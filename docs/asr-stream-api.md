# 语音解析接口文档

## 1. 语音解析

| 项目 | 说明 |
| --- | --- |
| 接口名称 | 实时语音转文字流式识别 |
| 通信协议 | WebSocket |
| 接口路径 | `/intelligentVoice/asr/stream` |
| 数据流向 | 双向（全双工）：客户端上传音频流，服务端下行识别文本 |

### 1.1 连接地址

```text
ws://{host}:{port}/intelligentVoice/asr/stream
```

#### 连接与会话生命周期

- WebSocket 为长连接，同一条连接可承载多个顺序执行的识别会话。
- 收到第一段二进制音频时开始一个识别会话。
- 每句话可返回多次 `isFinal: false` 的动态结果；识别出该句最终内容后自动返回 `isFinal: true`，随后继续识别下一句话。
- `{"action":"stop"}` 结束当前识别会话；如果当前句尚未完成，服务端先返回该句的最终结果。如果没有未完成内容，则返回 `text` 为空的最终响应作为 Session 结束确认。
- `stop` 的结束确认返回后，客户端可继续发送下一段二进制音频以开始新的识别会话。
- 用户离开页面、服务异常或连接连续 60 秒无数据时关闭 WebSocket。

### 1.2 连接 URL 查询参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `sampleRate` | int | 否 | `16000` | 音频采样率。可选值：`8000`（电话场景）、`16000`（麦克风场景） |
| `language` | String | 否 | `zh-CN` | 识别语种。可选值：`zh-CN`（中文）、`en-US`（英语）、`ja-JP`（日语）等 |

连接示例：

```text
ws://localhost:8080/intelligentVoice/asr/stream?sampleRate=16000&language=zh-CN
```

### 1.3 音频参数要求

前端采集的音频必须满足以下格式要求，否则可能导致识别失败或杂音：

| 参数 | 要求 |
| --- | --- |
| 编码格式 | PCM（无压缩裸流，不要带 WAV/MP3 文件头） |
| 采样率 | 16000 Hz（或 8000 Hz，与连接参数 `sampleRate` 保持一致） |
| 位深 | 16-bit |
| 字节序 | 小端序（Little-Endian） |
| 声道数 | 单声道（Mono） |
| 分片大小 | 建议 1280 字节（40 ms）或 3200 字节（100 ms） |
| 发送间隔 | 按实际采集间隔实时发送，禁止一次性发送全部音频 |

### 1.4 入参数据说明

连接建立后，客户端可发送两种类型的数据。

#### 二进制音频流

直接通过 `WebSocket.send()` 发送二进制音频流数据。

#### 文本控制指令

通过 `WebSocket.send()` 发送 JSON 文本，用于控制识别会话。

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `action` | String | 是 | 控制动作。当前仅支持 `stop`：通知后端用户已停止说话，后端结束当前识别会话并返回最后一句的最终结果 |

发送示例（结束识别）：

```json
{
  "action": "stop"
}
```

### 1.5 响应数据说明

服务端返回的识别结果为 JSON 字符串，结构如下。

#### 响应字段

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int | 状态码。`0` 表示正常，其他值表示错误 |
| `msg` | String | 状态说明或错误信息 |
| `data` | object | 识别结果对象，字段见下表 |

#### `data` 对象字段

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| `text` | String | 识别出的文本内容 |
| `isFinal` | boolean | 是否为当前句子的最终结果。`false` 表示当前句的中间结果，需替换上一次动态内容；`true` 表示当前句已完成，需替换动态内容并转为已确认内容。`isFinal: true` 不代表 WebSocket 连接关闭 |

#### 错误码

错误响应保持相同的 JSON 结构，`data.text` 为空字符串。

| 错误码 | 说明 |
| --- | --- |
| `1001` | 连接查询参数无效 |
| `1002` | 消息格式或音频数据无效 |
| `1003` | 当前会话状态不允许执行该操作 |
| `2001` | ASR 服务不可用或返回无效响应 |
| `2002` | 连接 ASR 服务超时 |
